# 자동 정리 서버 배포 방법 (Cloudflare Workers, 명령어 없이)

1. https://dash.cloudflare.com 에서 무료 계정을 만든다. (직접 가입)
2. 왼쪽 메뉴 **Workers & Pages → Create → Create Worker** → 이름 정하기 → **Deploy**.
3. 배포된 Worker에서 **Edit code**를 눌러 기존 코드를 지우고 `worker.mjs` 내용을 통째로 붙여 넣은 뒤 **Deploy**.
4. **Settings → Variables and Secrets**에서 아래를 추가한다.

| 이름 | 종류 | 값 |
|---|---|---|
| `ACCESS_CODE` | Secret | 직접 정한 긴 비밀 코드 (앱에 입력) |
| `AI_KEY` | Secret | AI 서비스 API 키 (Gemini 또는 Claude) |
| `AI_PROVIDER` | Text | `gemini` 또는 `claude` |
| `AI_MODEL` | Text | (선택) 모델 이름. 비우면 기본값 |
| `ALLOW_ORIGIN` | Text | `https://jungyeonsu0330.github.io` |

5. Worker 주소(`https://이름.계정.workers.dev`)를 복사한다.
6. 앱 **메뉴 → AI 설정 → 자동 정리 서버**에 주소와 접근 코드를 넣고 **서버 연결 테스트**를 누른다.

## 안전 수칙
- `AI_KEY`와 `ACCESS_CODE`는 **Secret**으로만 저장한다. 채팅·코드·GitHub에 붙여 넣지 않는다.
- AI 서비스 쪽에서 **사용 한도(예산)** 를 걸어 둔다.
- 접근 코드가 유출되면 Cloudflare에서 값을 바꾸고 앱에서 다시 입력한다.
